# 개인자산관리 웹사이트

브라우저만으로 동작하는 개인자산관리 웹사이트입니다. 별도의 서버나 빌드 과정 없이 `index.html`을 열면 바로 사용할 수 있으며, 데이터는 브라우저 localStorage에 저장됩니다.

## 실행 방법

```bash
# 방법 1: 파일 직접 열기
index.html 을 브라우저에서 열기

# 방법 2: 간단한 로컬 서버
python3 -m http.server 8000
# → http://localhost:8000 접속
```

## 화면 구성 (3패널)

| 패널 | 내용 |
|------|------|
| 좌측 | **자산 구성** — 부동산 · 주식 · 가상자산 · 예금 카테고리별 항목 입력/관리 |
| 중앙 | **자산 상세 구성** — 좌측에서 자산 항목을 클릭하면 해당 자산의 구체적 구성을 도넛 다이어그램으로 표시 |
| 우측 | **자산 추이** — 월별로 저장된 자산의 추이를 막대차트로 표시 (전체 선택 시 카테고리별 누적 막대) |

## 주요 기능

- **입력 시점(월 단위) 저장**: 자산 항목 입력 전에 입력 시점을 월 단위로 선택하고, 월별 스냅샷으로 저장합니다.
- **부동산**: 매매 / 전세 / 월세 구분. 전세·월세는 보증금을 입력합니다(월세는 월세액도 기록 가능).
- **주식 / 가상자산**: 종목을 추가하고 매입금액을 입력합니다. 현재 평가금액(선택)을 입력하면 수익률이 표시되고 자산 가치에 반영됩니다.
- **예금**: 정기예금 / 적금 / 주택청약저축 중 선택.
  - 적금·주택청약저축은 월 불입금액을 입력합니다.
  - 주택청약저축은 최초 가입일을 입력하면 현재까지의 가입기간(N년 M개월)을 자동 표기합니다.
- **저장 및 수정 잠금**: 최종 입력 후 저장하면 해당 월 데이터가 잠기며, 수정하려면 숫자 4자리 비밀번호를 입력해야 합니다. 비밀번호는 최초 저장 시 설정합니다.
- **밝게/어둡게 테마 전환**: 상단 우측 버튼으로 전환하며 선택이 유지됩니다.
- **실시간 시계**: 상단 우측에 연도·날짜·시간·백분의 일 초(1/100초)까지 표시합니다.
- **전월 대비 증감**: 총 자산 카드에 직전 월 대비 증감액과 증감률을 표시합니다.
- **이전 월 데이터 불러오기**: 새 월 입력 시 직전 월 데이터를 복사해 와서 바뀐 부분만 수정하면 됩니다.
- **데이터 백업**: 전체 데이터를 JSON 파일로 내보내기/가져오기 할 수 있습니다(가져오기는 비밀번호 확인 필요).
- **비밀번호 변경**: 현재 비밀번호 확인 후 새 4자리 비밀번호로 변경할 수 있습니다.

## 기술 스택

- 순수 HTML / CSS / JavaScript (외부 라이브러리·네트워크 의존성 없음)
- 도넛/막대 차트는 자체 SVG 렌더링
- 데이터 저장: `localStorage`
